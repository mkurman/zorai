# zorai-plugin-video-lab

A local video studio for zorai.

- **Storyboard to animatic**: write shots with beats, visuals and narration. Video Lab renders keyframes (local title cards or zorai's image provider), narrates them with Kokoro voices or zorai's cloud voice, animates them with push, pull and pan moves, and burns in word-timed karaoke captions heard back by Whisper. The animatic is free to make and is the gate before any paid render.
- **Approved cloud render**: once the animatic matches the storyboard and you approve the estimate, video shots are generated by the provider in zorai's video settings, cached, fitted to each shot and assembled with the same narration and captions.
- **Transcript cuts**: index any recording (scene changes, keyframes, a word-timed transcript in SQLite with full-text search), then describe the edit in YAML: clips, filler words and pauses to remove, 16:9 / 9:16 / 1:1 / 4:5 outputs with smart crop or letterbox, and karaoke or plain captions. Encodes with NVENC when available.
- **App demos**: script a browser walkthrough (click, type, scroll, go to) with a line of narration per step. Chrome is recorded through its screencast with a visible cursor and click ripples, the camera eases in on each click and typed field, and each step waits for its narration.

Project documents are plain YAML (`storyboard.yaml`, `edit.yaml`, `demo.yaml`) and can be mirrored to a folder of your choice.

## Requirements

- `ffmpeg` and `ffprobe` with libass on the PATH
- `uv` (Video Lab runs its scripts with `uv run --python 3.12`)
- For local narration: Voice Lab installed and set up (Video Lab reuses its Kokoro voices)
- For demos: Google Chrome or Chromium
- An NVIDIA GPU is optional; it speeds up Whisper and encoding

## Install

```bash
zorai plugin add ./plugins/zorai-plugin-video-lab
```

Open **Plugins → Video Lab → Studio**. The first action asks you to allow the plugin to run programs on this computer.

## Settings

| Setting | Default | |
| --- | --- | --- |
| `whisper_model` | `small` | faster-whisper size for word timings and captions |
| `device` | `auto` | `auto`, `cuda` or `cpu` for Whisper |
| `scene_threshold` | `0.3` | Scene change sensitivity when indexing |
| `video_cost_per_second` | empty | Your provider's price per generated second, for the estimate |

## Development

```bash
cd video-lab
uv run --no-project --python 3.12 --with-requirements requirements.txt --with pytest python -m pytest -q -p no:cacheprovider tests
```
